Lab 1: The Tokenizer

Computers don't see words; they see a long string of characters. Your first job is to build a tool that "cuts" the string into a list of words.

build_tokenizer.py

# The Goal: Split text by spaces
def simple_tokenize(text):
1   tokens = []
2   current_word = ""
3
4   for char in text:
5     if char == " ":
6       # We found a space! Save word.
7       tokens.append(current_word)
8       current_word = ""
9     else:
10      # Build the word letter by letter
11      current_word += char
12
13  # Add the last word
14  tokens.append(current_word)
15  return tokens

Lab 2: The Normalizer (Stop Words)

Lab 3: Frequency Counter (BoW)

How do we turn text into math? By counting. This creates a "vector" (a list of numbers) representing the text.

bag_of_words.py

def count_frequencies(words):
1   # A dictionary (Hash Map)
2   bag = {}
3
4   for word in words:

7       bag[word] += 1

Lab 4: Sentiment Analyzer

Before Deep Learning, we used "Lexicons" (Rule-based dictionaries). If a word is good, +1 score. If bad, -1 score.

sentiment.py

# The "Lexicon"
scores = {"good": 1, "love": 1, "bad": -1, "hate": -1}

def get_sentiment(text):
1   score = 0
2   words = text.split()
3
4   for word in words:
5     if word in scores:
6       score += scores[word]
7
8   if score > 0: return "POSITIVE"
9   if score < 0: return "NEGATIVE"
10  return "NEUTRAL"
