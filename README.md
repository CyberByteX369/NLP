# 🧠 NLP: Zero to Hero (Interactive Learning Suite)

A collection of interactive, single-page educational websites designed to teach Natural Language Processing (NLP) concepts from absolute basics to implementation. 

This repository is designed for students and beginners who want to understand **how** NLP works under the hood, not just how to use the libraries.

## 📂 Project Structure

This repository contains three progressive learning modules. Each module is a standalone HTML file containing all necessary CSS and JavaScript.

### 1. `v1-beginner-guide.html` (The Theory)
**"From Zero to Hero"**
- A modern, responsive landing page introducing the world of NLP.
- Covers the "Big 4" libraries: NLTK, spaCy, scikit-learn, and Transformers.
- Includes a visual roadmap and real-world use cases.
- **Goal:** Understand *what* NLP is and *why* it matters.

### 2. `v2-deep-dive.html` (The Concepts)
**"Under the Hood"**
- A deep dive into the standard NLP Preprocessing Pipeline.
- Interactive visualizations for:
  - **Tokenization:** Breaking text into units.
  - **Stop Word Removal:** Cleaning noise.
  - **Vectorization:** Converting text to math (Bag of Words vs. Embeddings).
- **Goal:** Understand the *math and logic* before the code.

### 3. `v3-builder-labs.html` (The Workshop)
**"Build It Yourself"**
- A fully interactive "Code Lab" interface running entirely in the browser.
- Users actively build 4 core NLP tools:
  1.  **Tokenizer:** Writing the logic to split strings.
  2.  **Normalizer:** Creating filters to clean text.
  3.  **Frequency Counter:** Implementing "Bag of Words" logic.
  4.  **Sentiment Analyzer:** Building a rule-based AI judge.
- **Goal:** Master the algorithms by writing them (simulated) yourself.

## 🚀 How to Use

No installation, Python, or server is required. These are "Client-Side" educational tools.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/nlp-learning-suite.git](https://github.com/your-username/nlp-learning-suite.git)
    ```
2.  **Open the files:**
    - Navigate to the folder.
    - Double-click any `.html` file to open it in your web browser (Chrome, Edge, Firefox, etc.).

## 🛠️ Technologies Used

- **HTML5:** Semantic structure.
- **CSS3:** Modern Flexbox/Grid layouts, dark mode themes, and responsive design.
- **Vanilla JavaScript:** All logic (tokenization, sentiment analysis) runs natively in the browser without external libraries.

## 🎓 Learning Path

For the best experience, go through the files in this order:
1.  **Start with V1:** To get the big picture.
2.  **Move to V2:** To visualize the pipeline.
3.  **Finish with V3:** To test your skills in the labs.
